What this does not establish

This is arithmetic evidence, not semantic relevance, score calibration, retriever independence, causal improvement or a performance benchmark. The native fuse-search command ranks explicit query variants using the existing exhaustive BM25 index. The browser replays those supplied rankings exactly; it does not claim exact cross-language BM25 logarithms or vendor-engine parity.

RRF: Cormack, Clarke & Buettcher, SIGIR 2009. Weights, depth, candidate union and tie policy are explicit local choices. Duplicating a source changes influence. Judgments and controls are illustrative, not a real-world quality benchmark.
